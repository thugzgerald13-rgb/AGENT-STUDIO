Frequently asked questions

Which LLMs can I use?+

Any OpenAI-compatible endpoint: OpenAI, Groq, OpenRouter, Together, or a local model via Ollama. You bring your own API key in Settings.

What is a crew run?+

A crew run lets several agents work the same task in sequence. Each agent sees all previous responses, so you can build research → write → critique loops automatically.

Do my LLM keys stay private?+

Yes. Each user's LLM configuration is stored per-account and never shared. If you self-host, everything stays on your server.

Can I self-host this?+

Absolutely. It's a single Node.js app with no database required. Set your Stripe keys to enable paid upgrades, or leave them out and run it free-only.
